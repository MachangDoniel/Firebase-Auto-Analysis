* Issue: The iOS UI slider (UISlider / SwiftUI Slider) fires a GA4 custom event on every continuous value update frame during a drag gesture, rather than firing once when the user releases continuous drag (touchUpInside / onEditingChanged).
* Impact: Data skewing, network bandwidth overhead on mobile, and inflated GA4 quota consumption.
