### P0 (Immediate Blockers - Next Sprint)

1. **MSS Version 1.3.10 UI Blocking Fix (Engineering):**
   * *Issue:* Active user engagement plummeted from **82.7% to 26.9%** with 0 registered crashes.
   * *Action:* Investigate the new paywall layout and navigation stack in build `1.3.10`. Look for un-clickable close buttons, frozen view transitions, or UI elements blocking interaction on initial load.
2. **Resolve StoreKit Transaction Bug in Vocal Cleaner (Engineering):**
   * *Issue:* Duplicate transaction logs and sandbox purchases leaking into production GA4 metrics from Egypt.
   * *Action:* Verify that `finishTransaction(_:)` (StoreKit 1) or `Transaction.finish()` (StoreKit 2) is executed immediately upon every transaction state completion. Implement cryptographic receipt validation to filter out sandbox transactions from production GA4 properties.

### P1 (UX & Optimization - 30-Day Window)

1. **Debounce Audio Control Sliders in MSS (Telemetry/Engineering):**
   * *Issue:* High event volume for `player_pitch_changed` (53.9/user) and `player_tempo_changed` (69.2/user) causing unnecessary network traffic.
   * *Action:* Implement slider event debouncing. Only fire the GA4 event once the user has finished dragging the slider (on the `touchUp` event), rather than tracking every step of the movement.
2. **Localization & Global Price Optimization (Growth/Product):**
   * *Issue:* Over **84% of revenue** is heavily concentrated in Japan and South Korea, leaving the app highly vulnerable to changes in those specific markets.
   * *Action:* Run an A/B test in Europe and North America with localized App Store screenshots and lower introductory price points to expand the app's global footprint.

### P2 (Infrastructure Cleanup - 90-Day Window)

1. **Fix Vocal Cleaner Background Session Bug (Telemetry):**
   * *Issue:* Returning users logging 0% engagement and 0 page views despite sessions showing exactly 10 minutes in duration.
   * *Action:* Implement proper background state listeners (`sceneDidEnterBackground`). Ensure that GA4 session timers are paused when the app is minimized to prevent artificial inflation of average session duration.
2. **Decouple GA4 Stream Architecture (Infrastructure):**
   * *Issue:* Multiple products sharing a single GA4 property ID risks data pollution.
   * *Action:* Migrate Vocal Cleaner to a dedicated GA4 property, or enforce strict namespace rules (e.g., prefixing all custom parameters and event names with `mss_` or `vc_`) to keep your analytics clean.
