Telemetry Bug Analysis: Slider Debouncing Failure

The events player_tempo_changed (562.8 per user), player_pitch_changed (434.7 per user), and player_stem_balance_changed (252.2 per user) are firing continuously as users adjust the slider.

Instead of waiting for the user to finish adjusting, the app fires an event for every slider increment.

  • Impact: This inflates our GA4 event ingestion volume, leading to higher data costs and skewed session calculations (averaging 100 events per session).
  • Resolution: Implement slider debouncing. The app should only fire a single GA4 event when the user lifts their finger from the slider UI element (UIControl.Event.editingDidEnd or the SwiftUI equivalent).
