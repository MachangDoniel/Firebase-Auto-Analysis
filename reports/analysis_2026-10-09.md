#### Telemetry Analysis (Slider Debouncing Bug)
The telemetry logs reveal a major issue: **`player_pitch_changed` runs 282.3 events per user**, `player_tempo_changed` runs 125.2, and `player_stem_balance_changed` runs 72.0.

This is a classic tracking error. When a user slides the control knob, the app sends a GA4 event for *every single point changed* instead of waiting for the user to lift their finger. This debouncing issue floods GA4 with thousands of unnecessary events, inflating our database volume and increasing network usage.
